# flask-random-frases in the AWS


* Create virtualenv:  `virtualenv ~/.venv && source ~/.venv/bin/activate`
* Install:  `make all`
* Run:  `python app.py`

## Deploy in docker 
```
docker run -it -p 127.0.0.1:8080:8080 --name flask-random ramr2900/flask-random  
```
